Ochtendkaarten, van vraag naar kaart.

  1. Stap 1. De verkoper typt een gewone zin. Voorbeeldzin: “Drie in Spanje.”

  2. Stap 2. Een skill maakt daar één read-only vraag van: land Spain, limiet 3, geen sector. Bij een onduidelijke sector één terugvraag, anders meteen de smallere lijst.

  3. Stap 3. De deur geeft kaarten terug. Per kaart alleen: naam, medewerkers, fit, timing, priority, kop, share-link.

  4. Stap 4. De verkoper opent één share-pagina. De scores daar zijn de live cijfers uit de database, dezelfde als op de kaart.
